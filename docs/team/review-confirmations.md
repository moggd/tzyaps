# Журнал особистих рецензій

Марко передав чотири відповіді від 28.11.2026. Нижче зафіксовано заявлений обсяг і результат погодження. Позначки щодо конкретної редакції, класу чи картки потребують ідентифікатора матеріалу від рецензента.

| Рецензент | Заявлений обсяг і результат | Звірка з досьє |
|---|---|---|
| Гавриш Роман | JUnit-клас колеги й підсумковий звіт С5. Погоджено, зауважень немає. | Результат компіляції узгоджується з наявністю двох звітів Surefire з виконаними тестами. Назва класу та редакція звіту не вказані. |
| Дарнопих Артем | JUnit-клас колеги й метрики С3–5. Погоджено, зауважень немає. | У відповіді немає чисел або редакції. Поточні метрики звірені технічно. Потрібна назва класу. |
| Лебідь Антон | JUnit-клас колеги, 46 кейсів, 8 баг-репортів і звіт регресії. Погоджено, критичних зауважень немає. | TC-01–TC-46 збігаються порядковими номерами з TC-001–TC-046. Редакція невідома. Для TC-047 і TC-048 погодження не надходило. BUG-01–BUG-08 не збігаються з підтвердженим переліком. Висновок про стабільність потребує уточнення через MOD-008 і залишкові падіння v2. |
| Микуляк Марко | Класи трьох колег, загальна Maven-збірка та документація С3–5. Погоджено, зауважень немає. | Назви і коміти класів не вказані. Особисті коміти з цими класами у робочій гілці відсутні. Поточні тести виконалися, але обидві команди Maven завершилися помилкою через невдалі твердження. |

**Технічне звіряння.** На v1 пройшли 64 з 83 викликів, на v2 — 74 з 83. На обох версіях 0 помилок виконання і 0 пропусків. Сім стартових тестів пройшли окремим запуском. Новий дефект v2 MOD-008 відтворено на тому самому наборі. Підтверджені ID OrangeHRM — BUG-002, BUG-003, BUG-010, BUG-011, BUG-013, BUG-014, BUG-015, BUG-016. ## Уточнення для одного повідомлення кожному

- Роман. «Підкажи назву JUnit-класу та дату, назву файлу або коміт перевіреної версії звіту С5. Якщо маєш актуальну версію, підтвердь висновок No-Go та 116 Passed / 19 Failed / 2 Blocked».
- Артем. «Підкажи назву JUnit-класу й надішли посилання або підсумковий рядок тієї таблиці метрик, яку перевірив. Поточний повтор має 116 Passed / 19 Failed / 2 Blocked і pass rate 85,9%».
- Антон. «Укажи JUnit-клас, версію кейсів і точні ID восьми карток. Додатково перевір TC-047 і TC-048. Чи погоджуєшся з формулюванням: v2 виправила чотири дефекти, три відтворено повторно й підтверджено новий MOD-008?».
- Марко. «Укажи назви та посилання на коміти трьох перевірених класів, а також лог чи точну команду для зеленого запуску. У Starter 7/7, у збережених прогонах модуля v1 — 64/83, v2 — 74/83. Власні внески зарахуємо за фактичними комітами».
