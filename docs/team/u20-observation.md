# Картка спостерігача для U-20

**Мета.** Працівник, який ще не користувався формою відпустки, самостійно подає заявку за 180 секунд або швидше. Початок — відкритий Dashboard власного синтетичного ESS. Виконавець і спостерігач різні.

## Перед початком

Спостерігач перевіряє в окремій сесії, що для нового власного ESS є доступний тип і ліміт щонайменше на один обраний робочий день. У двох технічних перевірках для 03.12.2026 тип CAN - Bereavement показав 12.00 Day(s). Публічний стенд скидає дані, тому перед сеансом потрібна коротка повторна звірка. Виконавцеві відкривають Dashboard. Навігацію, підказки та скріншоти форми заздалегідь не показують.

Дайте лише завдання з типом та датою. «Самостійно подайте заявку на один день відпустки на [дата] з типом [тип]». Запустіть таймер одразу після прочитання завдання. Зупиніть після підтвердження відправлення заявки. Перевірте власний Pending Approval. Якщо застосунок або баланс заблокував завдання, зазначте точну причину.
