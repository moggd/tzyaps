## Мінімальний контроль без додаткового редагування

1. Відкрити `test-cases.xlsx` і перевірити аркуші `Test cases`, `Coverage`, `Review`, `Independent fixtures`, `Final corrections`.
2. Відкрити `execution-log.xlsx` і перевірити історичний `Run 1`, `Screenshot observations` і `Run 2 - pending`.
3. У GitHub зіставити Issues #1 і #2 з вкладеннями `BUG-002-1.png` та `BUG-001-1.png`.
4. Для повторної здачі не приписувати зміненим кейсам рецензування, якого не було, і не зараховувати непідтверджені дефекти до актуальної статистики.
