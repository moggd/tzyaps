### BUG-001
* **Title:** Recruitment: відсутня функція експорту активної вакансії у форматі XML (F-130)
* **Labels:** `status:open`, `sprint:3`, `severity:major`, `priority:P2`
* **Severity:** Major
* **Priority:** P2
* **Linked:** `TC-018` (failed), `TC-023` (blocked); вимога `F-130` (SRS v1.1)
* **Description:**  
  Вимога `F-130` (виправлена SRS v1.1) визначає, що активна вакансія генерується у форматі XML для ручного експорту на портали вакансій. На сторінці створення та редагування вакансії (`Edit Vacancy`) інтерфейс містить лише поля редагування та посилання RSS/Web, але елемент керування для завантаження XML-файлу вакансії відсутній.  
  **Обґрунтування Severity (Major):** ключова функція експорту вакансії, зафіксована у специфікації, не реалізована, хоча саме створення вакансії працює.  
  **Обґрунтування Priority (P2):** дефект блокує виконання тест-кейсу `TC-023` (перевірка структури згенерованого XML-файлу).
* **Steps to reproduce:**  
  1. Відкрити `https://opensource-demo.orangehrmlive.com` у Chrome (нова сесія інкогніто).  
  2. Увійти під обліковим записом адміністратора (`Admin` / `admin123`).  
  3. У бічному меню перейти в `Recruitment` та відкрити вкладку `Vacancies`.  
  4. Натиснути кнопку `+ Add`, ввести `Vacancy Name`: `QA Engineer Middle`, обрати `Job Title`: `QA Engineer`, `Hiring Manager`: `Admin`, залишити перемикач `Active` увімкненим і натиснути `Save`.  
  5. Оглянути панель інструментів та форму на сторінці `Edit Vacancy` після збереження.
* **Actual result:**  
  Після кроку 4 вакансію збережено, але на сторінці `Edit Vacancy` (крок 5) відсутня кнопка або посилання для експорту вакансії у формат XML.
* **Expected result:**  
  Згідно з вимогою `F-130` (SRS v1.1), після збереження активної вакансії на сторінці `Edit Vacancy` відображається елемент експорту у формат XML, натискання якого завантажує структурований `.xml` файл вакансії.
* **Environment:** demo `https://opensource-demo.orangehrmlive.com` (2026-11-09); Chrome 130.0.6723.92; Windows 11 Pro; обліковий запис `Admin` (роль Admin).
* **Attachments:** `BUG-001-1.png` — сторінка `Edit Vacancy` після збереження активної вакансії без кнопки експорту XML.

* **Severity:** Trivial
* **Priority:** P3
* **Linked:** `TC-002`; вимоги `F-20`, `GUI-20` (SRS v1.1)
* **Description:**  
  На сторінці входу (`/auth/login`) при натисканні кнопки `Login` з невірними обліковими даними кнопка не змінює стан (не блокується і не відображає індикатор запиту), через що при повільному з'єднанні користувач може натиснути її повторно, а банер `Invalid credentials` миготить без оновлення часу.  
  **Обґрунтування Severity (Trivial):** косметичний недолік зворотного зв'язку елемента керування, що не впливає на функціональність автентифікації.  
  **Обґрунтування Priority (P3):** інших тест-кейсів не блокує.

  1. Відкрити `https://opensource-demo.orangehrmlive.com` у Chrome (нова сесія інкогніто).  
  2. У поле `Username` ввести `Admin`.  
  3. У поле `Password` ввести `wrongpass123`.  
  4. Натиснути кнопку `Login` та простежити за станом кнопки під час виконання HTTP-запиту.

* **Expected result:**

* **Environment:** demo `https://opensource-demo.orangehrmlive.com` (2026-11-08); Chrome 130.0.6723.92; Windows 11 Pro; без входу в обліковий запис.
