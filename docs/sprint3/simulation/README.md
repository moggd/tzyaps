# Навчальна симуляція тестів — додатковий матеріал

Ця папка містить альтернативний навчальний прогін з **30 модельними сценаріями** та **30 картками з текстовими описами інтерфейсу**. Зображення явно містять позначення `STUDY SIMULATION` і **не є скріншотами живого OrangeHRM**.

`test-cases-simulation.xlsx` і `execution-log-simulation.xlsx` — вихідні моделі Gemini. `review-findings.md`, `bug-reports-simulation.md` і `VALIDATION.json` збережені для простежуваності. Дев'ять SIM-BUG — гіпотетичні картки, а не дев'ять підтверджених дефектів.

Сім нових тест-дизайнів TC-024–TC-030 перенесено до основного `../test-cases.xlsx`, залишивши історичні дані та всі справжні докази без змін.
