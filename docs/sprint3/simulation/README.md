# Оновлені картки навчальної симуляції TC-001—TC-030

23.11.2026 отримано **другу серію з 30 зображень**, яка замінює попередні файли `submitted-captures/TC-XXX-submitted.png`.

Кожна картка містить ID, вхідні дані, очікуваний результат і поле `MODELED ACTUAL`. Тому ці матеріали підтверджують оформлення 30 навчальних сценаріїв і змодельованих результатів, але **не доводять виконання тестів у живому вебзастосунку**.

- [Індекс 30 нових карток](evidence-index.md)
- `attachments/` — початкові картки симуляції; залишені для порівняння.
- `../attachments/` — попередньо надані окремі докази, не змінені цим архівом.
- `test-cases-simulation.xlsx`, `execution-log-simulation.xlsx` — раніше створений модельний прогін.
- `VALIDATION.json` — статистика початкової моделі, не журнал фактичного запуску.

**GitHub:** ці картки можна додавати як додаткові навчальні матеріали без зміни статусів реального Run 1/Run 2 і без приписування командного рев’ю.
