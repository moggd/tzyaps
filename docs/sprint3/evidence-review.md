## Детальні спостереження

### BUG-001: Частково підтверджено
Сторінка Edit Vacancy для QA Engineer Middle, активна вакансія; видно RSS/Web і немає видимого XML-експорту. Job Title=Automation Tester, Hiring Manager=Timothy Lewis Amiano, тобто вхідні дані відрізняються від Run 1. Скріншот не доводить відсутність серверного XML-експорту поза цією сторінкою.

### BUG-002: Візуально підтверджено
У System Users є обліковий запис тест_юзер1 (ESS, James Butler): кирилиця та підкреслення збережені. Це відповідає проблемі F-30 з SRS 1.1. Фактичний працівник відрізняється від старого репорту.

### BUG-003: Частково підтверджено
Форма Add User з username qaweak26, індикатор Very Weak; кнопка Save активного вигляду, але немає скріншота після натискання та підтвердження створення акаунта. Не доводить, що слабкий пароль фактично збережений.

### BUG-004: Не підтверджено
Зображення показує іншу, візуально старішу форму Leave Apply (US-Casual, Holiday, dd-mm-yyyy), ніж використаний demo OrangeHRM OS 5.9. Немає результату 4.00 проти 2.00. Окремий знімок TC-010-blocked.png демонструє 0.00 балансу і незаповнену Duration, а не розрахунок.

### BUG-005: Частково підтверджено
Є форма з введеним довгим Username і збережений користувач у System Users. Проте на першому знімку кінцевий пробіл не можна однозначно побачити, а довжину рядка не підтверджено незалежним виміром. Отже автоматичне обрізання пробілу не доведене.

### BUG-006: Спостереження, не доведений SRS-дефект
Edit Timesheet при 1280×720 показує повідомлення валідації для 25 годин, що переноситься вузькими рядками. Не видно перекриття сусідньої комірки; F-120 не встановлює правил розташування тексту помилки.

### BUG-007: Доказ відсутній
Зображення BUG-007 не надіслано. Не можна вважати дефект доведеним; початковий тест суперечить власному очікуванню щодо доступності прокрутки.

### BUG-008: Не підтверджено
Червоне Required стоїть під порожнім First Name, тоді як символ K введено в Last Name. Це нормальна валідація іншого обов’язкового поля, а не доказ затримки зникнення повідомлення Last Name.

### BUG-009: Не підтверджено; TC-002 спостережено як passed
На формі входу видно Invalid credentials. Критерію індикатора кнопки немає у відповідних вимогах. Скріншот підтримує успішне спрацювання F-20, але не дефект BUG-009.

## Окреме спостереження для TC-010
`TC-010-blocked.png`: форма Leave Apply, CAN - Personal, інтервал 27–30.11.2026, Leave Balance = 0.00 Day(s), поле Duration не вибрано. Підтверджує невиконання потрібних передумов; **не доводить**, що вихідні дні включено в тривалість.

## Що залишилося до здачі
- Документувати справжні GitHub Issues і посилання лише для підтверджених дефектів.
- Завершити незалежні передумови тест-кейсів, повторно перевірити змінені кейси й отримати реальне рецензування.
- Добрати ≥8 справжніх дефектів (якщо норматив викладача лишається чинним), не зараховуючи непідтверджені спостереження.
- Погодити в SRS розбіжність F-20 і GUI-20; перевірити повний текст SRS 1.1, який наразі місцями скорочений.
- В історичному Run 1 зберегти попередні записи як історію, а новий прогін відокремити.
