# Протокол ретроспективи (Спринт 2)
**Присутні:** Марко, Роман, Артем  
**Модератор:** Марко (Скрам-майстер)

**Start (почати робити):** 
1. Проводити незалежний аудит вимог строго окремо, щоб уникнути групового мислення, як вимагає методологія.
2. Детальніше прописувати "Опис" у плані тестування, прив'язуючи його до демо-застосунку.

**Stop (припинити робити):** 
1. Формулювати вимоги до інтерфейсу абстрактними словами (наприклад, "зручно" чи "швидко").

**Continue (продовжити робити):** 
1. Використовувати перехресне рецензування перед злиттям гілок у GitHub.
