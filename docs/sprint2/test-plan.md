# План тестування продукту «Персонал+»

## 1. Продукт і межі тестування
**Продукт:** HRM-система «Персонал+» (версія 1.0), зокрема новий модуль самообслуговування для відпусток (Leave) та його інтеграція з модулями PIM і Time.
**Об'єкт тестування:** Бізнес-логіка розрахунку відпусток, графічний інтерфейс подання заявок, процеси погодження керівником.
**Поза межами тестування (Out of Scope):** Мобільний застосунок (виведено поза обсяг релізу 1.0), апаратне забезпечення серверів.

## 5. Інструменти, середовище, тестові дані
*   **Інструменти тестування:** JUnit 5 (модульне), Postman та REST Assured (інтеграційне API), JMeter (навантажувальне).
*   **Тестове середовище:** Тестовий та Beta сервери з розгорнутою копією OrangeHRM v1.0. Браузери: Chrome, Firefox, Safari, Edge (останніх версій).
*   **Тестові дані:** Попередньо створені демо-користувачі в базі (Admin: `admin/admin123`, Employee: `test_emp_01`, Supervisor: `test_sup_01`).

## 6. Ризики і припущення
*   **Припущення:** Замовник вчасно надасть доступ до тестового середовища. API модулів Leave та PIM не зміняться до кінця тестування.
*   **Ризики:** Відсутність реальних даних для навантажувального тестування (пом'якшення: створення синтетичних даних у базі); затримка з погодженням критичних дефектів замовником.
