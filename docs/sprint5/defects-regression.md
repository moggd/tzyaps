## MOD-008 · BL-40 · заявка на весь доступний баланс

**Регресія v2.** Severity Major, Priority P2. Відхилення блокує подання заявки на повний залишок. Середовище — personal 2.0.0, OpenJDK 17, macOS 27.2.1, 28.11.2026.

1. Підготувати оригінальний v2 за README.
2. У каталозі модуля виконати `mvn -Dtest=LeaveCalculatorTest#requiresPositiveDurationWithinBalance test`.
3. Звірити параметризований запуск №5 з аргументами `balance=5, duration=5`.

**Очікувано.** `true`, оскільки 1 ≤ duration ≤ balance.
**Фактично.** v2 повертає `false`. Цей набір у v1 пройшов, сусідні точки з 4 та 6 днями на v2 пройшли. Доданий окремий тест для (1, 1) підтвердив те саме відхилення. Доказ — [XML v1](surefire-v1/TEST-ua.kpi.tzyapz.personal.LeaveCalculatorTest.xml) та [XML v2](surefire-v2/TEST-ua.kpi.tzyapz.personal.LeaveCalculatorTest.xml).
