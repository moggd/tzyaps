# Технічне рецензування спринтів 3–5

28.11.2026 · Виконавець Codex. Рецензії студентів фіксуються після їхнього особистого підтвердження.

## Тест-кейси

У [Review](../sprint3/test-cases.xlsx) є окремий результат для кожного з 48 кейсів. Звірено ID, передумови й дані, спостережуваний очікуваний результат та прив’язку до доказу. Виправлено кроки, де старі дані або повний сценарій не відповідали фактичному спостереженню. Зокрема TC-009 працює лише з власною карткою, TC-011 використовує фактичні дати, TC-015 — синтетичного працівника та 2,50 дня, TC-029 — лише підтверджений статус Rejected, TC-034 — факт наявності фільтра Include.

TC-044 відхиляє заявку й показує очікуване повідомлення біля балансу. Текст окремого тосту залишено як спостереження. Для F-130 доступний RSS з XML-елементом власної вакансії, тому відсутність окремої кнопки не зараховано як підтверджений дефект. У GUI-20 лишається суперечність щодо точного тексту.
